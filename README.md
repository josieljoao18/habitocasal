# 💑 HabitFlow - App de Hábitos para Casais Cristãos

> "Melhor é serem dois do que um" - Eclesiastes 4:9

Um aplicativo web para casais cristãos criarem e acompanharem hábitos juntos, fortalecendo o relacionamento com Cristo.

## ✨ Funcionalidades

- 🎯 **Hábitos flexíveis** - Diários, semanais ou personalizados (a cada X dias)
- 🔥 **Sistema de streaks** - Mantenha a motivação com ofensivas de dias consecutivos
- 🎉 **Confete e som** - Feedback visual e sonoro ao completar hábitos
- 📊 **Barra de progresso** - Visualize o percentual de hábitos concluídos no dia
- 📅 **Calendário semanal** - Navegue entre os dias com indicadores visuais
- 👥 **Perfis do casal** - Cada pessoa gerencia seus próprios hábitos
- 🌓 **Modo escuro/claro** - Alterne entre temas para conforto visual
- 📱 **Responsivo** - Funciona perfeitamente em celular e desktop
- ☁️ **Sincronização** - Firebase Realtime Database em tempo real
- 🔐 **Autenticação** - Login e cadastro com email/senha
